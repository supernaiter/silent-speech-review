## Required fixes, ordered by severity

1. **Major. Location:** Verdict ("The homophene-specific part, multiple heads, adds 0.3 LRW points ... while four depths add 1.3"); M06 paragraph "The paper's numbers place the gain away from the heads"; slots.json M06 note. **Evidence:** Target Table 2 at four depths: h=1 87.53%, h=8 88.51% (+0.98). Table 1's 0.3 is at one depth. The authors present multi-temporal context as part of the homophene mechanism (Sec. 3, "another key for distinguishing the homophenes"). **Fix:** State the interaction: "heads add 0.3 points at one depth and 1.0 at four depths (Table 2); depths add 0.6 with one head and 1.3 with eight (inference)". Drop "place the gain away from the heads". The defensible critique is that these are single runs with no seeds and the settings were selected on the test set.

2. **Moderate. Location:** M12 State of the art ("word-boundary input gave 55.7% on LRW-1000 ... above the paper's 53.82%") and Outrun 2 ("omits [8] at 55.7% with word boundaries"). **Evidence:** [8] Table 5: without word boundaries 85.0% LRW / 48.0% LRW-1000; with word boundaries 88.4% / 55.7%. The target uses no word boundaries. **Fix:** Remove the "omits" criticism, or recast it: "[8]'s like-for-like result is 48.0%, below the paper; 55.7% needs word-boundary input". Do not present 55.7 as "above the paper's" in a state-of-the-art line.

3. **Moderate. Location:** M02 usual approach ("all 3 decoders ... distil ...; LiRA [4] regresses PASE+") and Appendix M02 ("Prior ... audio-feature regression 0"). **Evidence:** In the M02 audit, LiRA (isca-ma21c-lira, 2021-06, read) is dated prior but left outside the pattern population. **Fix:** Count LiRA among the priors: "4 prior decoders: knowledge distillation 3, audio-feature regression 1 (LiRA, read), memory recall 0". Alternatively, say plainly that the pattern population of 3 misses LiRA, and drop "all".

4. **Moderate. Location:** Verdict, M02 and Appendix M02/M06 ([2] [concurrent]). **Evidence:** The label is correct under the date window, but the rules ask for same-group earlier designs to be counted as same-group priors. The target uses [2] as its baseline (Table 1 row 2, Table 6) and calls it "the previous state-of-the-art" (Sec. 4.2). The review's "standard; inherited from [2]" verdict depends on treating [2] as prior, while the Appendix lists it only as concurrent with prior memory recall 0. **Fix:** Keep [concurrent]. Add in the Appendix: "same-group prior: [2] (ICCV, Oct 2021), the target's own baseline". In M02, write "inherited from the same group's ICCV memory [2], which the paper uses as its baseline", so the standard verdict follows from the record.

5. **Moderate. Location:** M06 State of the art; components table, M06 row. **Evidence:** The M06 step is homophene disambiguation. [5] reports an all-pairs homophene evaluation (Sec. 4 "Distinguishing Homophenes", Fig. 3: relative F1 gain against grapheme edit distance) and notes that [1] covered only a subset of pairs. **Fix:** Make the M06 state of the art [5]'s all-pairs homophene analysis, with its metric and condition. Overall LRW and LRW-1000 accuracy can stay as context, labelled as not homophene-specific.

6. **Moderate. Location:** Outrun 3 ("is against a 2018 baseline"). **Evidence:** Target Sec. 4.2: "the baseline model that has the same architecture as the proposed method except for MVM". Table 5 labels the same row "Baseline (Afouras et al. 2018) 49.8". **Fix:** Credit the authors' description and state the inconsistency: the text describes a matched baseline, but the row is labelled with, and appears to take its value from, the 2018 paper. Whether it was retrained under the paper's LRS3 pre-training and hybrid CTC/attention loss is unclear. Add this to the Questions for the authors. (That 49.8 equals Afouras et al.'s published no-LM figure is unverified here.)

7. **Moderate. Location:** M06 usual approach and Appendix M06. **Evidence:** In the M06 audit, the prior language-model list includes cvf-prajwal20-lip2wav (video-to-speech, excluded by the stated rule) and isca-liu18h_cuedspeech. The population is selected by mentions of "viseme", which favours viseme-unit designs. The target's Table 3 peers in the same setting (LRW word classifiers with MS-TCN, DC-TCN or BiGRU) resolve homophenes only implicitly, through temporal context. **Fix:** Remove non-decoders from the 44 and recount. State that the viseme-unit majority comes from a mention-selected population, and that word-level LRW decoders at the time had no explicit homophene mechanism (the target's Table 3). Apply one setting definition across M06 and M12.

8. **Minor. Location:** M06 ("their ICCV memory gave about and amount 0.906 address similarity"). **Evidence:** [2] Fig. 4 and Sec. 4.3: the frames compared carry the same sound /aʊ/, and [2] reports the similarity as correct addressing. **Fix:** Drop it, or say that [2] shows clips of the same sound addressing the same slots, which is the mechanism the authors expect to fail for homophenes. The figure is not evidence of that failure.

9. **Minor. Location:** M02 State of the art (LiRA 88.1%). **Evidence:** [5] Table 1 lists LiRA at 590 h, with self-supervised pre-training on LRS3. **Fix:** Add "after self-supervised pre-training on unlabelled LRS3".

10. **Minor. Location:** M06 State of the art (SyncVSR 58.2%, "4.4 points above"). **Evidence:** [5] Table 1 does not say whether the CAS-VSR-W1K column uses word boundaries, and the same column holds Feng's word-boundary 55.7. **Fix:** Add "word-boundary use not stated", or soften the like-for-like comparison.

11. **Minor. Location:** M12 usual approach ("Tables 1-6") and Appendix M12 ("90 of 155 (pattern match, all years)"). **Evidence:** Target Tables 4–5 are LRW-1000 and LRS2. The rules forbid all-years counts for the usual approach. **Fix:** Write "Tables 1–3 and 6". Give a count dated against 2022-02, or set it as a mention count with matched=null.

12. **Minor. Location:** Outrun 4 and Verdict ("the homophene evidence is twelve words without sample counts"). **Evidence:** The LRW test split has 50 clips per word, so even percentages follow directly. Fig. 3 (SPEND/SPENT addressing) is the paper's other homophene evidence. **Fix:** State the denominator plainly ("50 test clips per word in LRW; +2% is one clip"). Mention Fig. 3 as a qualitative single-pair visualisation.

13. **Minor. Location:** M02 ("The memory's LRW effect is real: 86.1% ... to 88.5%"). **Evidence:** Target Table 1: single memory 86.1→86.9. **Fix:** Attribute +0.8 points (5.8% less error) to the memory recall inherited from [2], and 86.1→88.5 to the full MVM.

14. **Minor. Location:** M13 row ("Memory cost not given") and the references. **Evidence:** Target Sec. 4.2 says key and value memory parameters "remain similar" with the multi-head key. Reference 1 and its BibTeX note read "Read as arXiv v1 (April 2022), the AAAI camera-ready", which is a process note in published text. The reference also lacks the AAAI volume, pages and DOI (36(1), 1174–1182, doi:10.1609/aaai.v36i1.20003; unverified here). **Fix:** Credit the authors' parameter statement. Drop the "Read as" note from the published reference, and add volume, pages and DOI after checking them.

## Scores

- Procedure: 7/10. Comparator numbers were checked against read sources, conditions (word boundary, LM, run counts, hours) are mostly attached, and the chronology is defensible. Points are lost for the LiRA dating inconsistency, the M06 population (a non-decoder included, selection bias), the all-years M12 count, and a state-of-the-art line not on the slot's own step.
- Final text: 6/10. Clear position, correct arithmetic, and the Born-Again, back-end and Table 6 critiques are sound. The central "heads add only 0.3" framing omits Table 2's four-depth head effect. The Feng omission criticism compares across protocols. The LRS2 critique leaves out the authors' own description of their baseline.
