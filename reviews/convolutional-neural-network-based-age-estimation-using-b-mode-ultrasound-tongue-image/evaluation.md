## Required fixes, ordered by impact

1. Finding 2: verify that the 3.16% speaker-recognition error in [2] is for a single frame. The label "21 (0.25 sec)" suggests a 21-frame window. Restate the input length and speaker population exactly, because this number carries the central confound.
2. Finding 4: in the component table and the M12 state-of-the-art line, show Ribeiro 2019 [3] as the deciding prior for "behind". [5] is later and cannot be the reference for a "behind" verdict.
3. Finding 5: remove or rewrite "none matches a random frame split pooled across speakers (0)". The review's own comparators [3] and [5] report pooled multi-speaker conditions. The real gap is that the target has no held-out-speaker condition beside its pooled one.
4. Finding 1: mark "frames of the same children fall on both sides" as inference, or match it to the open question in Questions for the authors.
5. Finding 3: add one clause saying that "same setting" for M12 means same modality, corpus and split protocol, not the same task. Note that [6] is adult tongue tracking, so the two strictly same-setting earlier priors are [3] and [7].
6. Finding 6: do not call held-out speakers "the usual approach" on a 48-to-43 upper-bound tally.
7. Findings 7, 9, 14: add a UXTD quote for [5] or drop "UXTD"; soften "unsquared residual" to reflect text extraction; limit "one label per child" to UXTD.
8. Finding 13: justify Diener [4] over [2] as the M08 state of the art, or use [2].
