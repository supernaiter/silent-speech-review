# Pretraining Large Brain Language Model for Active BCI: Silent Speech

Jinzhao Zhou, Zehong Cao, Yiqun Duan, Connor Barkley, Daniel Leong, Xiaowei Jiang, Quoc-Toan Nguyen, Ziyi Zhao, Thomas Do, Yu-Cheng Chang, Sheng-Fu Liang, Chin-teng Lin  
arXiv 2025 · [arXiv](https://arxiv.org/abs/2504.21214)

**Section:** [Brain signals (EEG, MEG, intracortical)](../README.md#brain-signals-eeg-meg-intracortical) · **Review basis:** full_text+summary

Pretrains a brain language model on EEG with future-signal and frequency prediction, then classifies silently articulated words. Within-subject accuracy on held-out recording sessions reaches 39.6% for 24 words (TCNet 32.3%).

## Evaluation conditions

| | |
| --- | --- |
| Sensor | 128-channel Neuroscan scalp EEG (122 channels used) |
| Task | Closed-set word classification from EEG |
| Vocabulary | 24 fixed English words (also 6 semantic classes) |
| Speaker | Speaker-dependent |
| Session | Cross-session |
| Online / offline | Offline |
| Key result | 39.6% mean accuracy, 24-word classification, within-subject held-out sessions (47.0% for 6 semantic classes) |

**Limitations.** Only 12 healthy participants in a cue-driven seated lab setup with a dense EEG cap; no unseen-subject evaluation or confidence intervals; not tested online or for free conversation.

## 日本語レビュー

### 要点

未来の脳波も予測する事前学習で、同じ人の別収録における24語分類を39.6%へ改善した。無声で口を動かす限定語彙の実験であり、自由な思考や会話を読む技術ではない。

### レビュー

この研究の価値は、無声発話の脳波を正解ラベルなしで事前学習する際に、隠した信号の復元だけでなく未来の波形・周波数振幅・位相の予測を加えた点にある。健常な英語母語話者12人が、画面と音の合図に従い24語を声を出さずに口で表す。頭の中だけの発話とは区別が必要である。約120時間という規模は収録全体の報告で、無声発話区間だけの長さではない。各人16収録のうち検証用と試験用を各1つ取り分け、事前学習にも使わず、本人別に追加学習する。表1・2の平均正解率は24語分類39.6%、6意味群分類47.0%。比較法TCNetの32.3%・41.6%に対し、それぞれ7.3・5.4百分率ポイント高い。ただし同じLBLMの事前学習なしは35.3%・42.2%で、提案学習による差と他方式との差は分けて読む必要がある。単語分類は参加者ごとに11.7〜73.8%と幅があり、全員で改善したわけではない。未来脳波の短区間予測も改善するが、本文は約120ミリ秒を超えると実測とのずれが増すと述べる。これは分類の応答時間や将来の発話内容を先読みできる長さではない。意味分類の本文42.8%と表の47.0%、試行回数の説明など原稿内の不整合も残る。非侵襲の脳波による無声入力に向けた表現学習の貢献はある一方、未知の人や語、自由な文章、口を動かさない内言、患者、実時間の対話、長期安定性は未確認である。

### この論文の価値

本人別の無声発話分類で、ラベルのない脳波を時間と周波数の両面から学ぶ方法を比較可能な形で示したこと。完成した会話支援装置や、言語全般を理解する脳モデルの実証ではない。

### それまでの到達点

論文はEEGNet、TCNet、EEGConformer、STTransformerと事前学習済みLaBraMを比較。隠した信号の復元だけでは周辺からの補間に頼り、無声発話に有用な時間変化を学ばない可能性を課題に挙げる。

### 何が変わったか

正解ラベルを使わない事前学習を、隠した部分の復元から未来の波形・振幅・位相予測へ拡張し、本人別の分類に利用する。自由文生成や汎用言語理解の実証ではない。

### 分野での位置づけ

頭皮脳波による無声発話入力の基礎的な事前学習研究。口の運動を伴う英語単語の分類であり、内言の自由文復号や実時間の音声補綴とは評価範囲が異なる。

### 実用上の意味

少ない分類ラベルでも脳波収録を事前学習に使う設計の参考になる。収録間の変化に対する平均改善は有用だが、日常の通信手段としての精度と操作性は未確認。

### 前進した軸

同じ人の未使用収録への分類精度、正解ラベルを使わない脳波事前学習、時間・周波数を合わせた表現学習。

### 未解決の軸

未知の人・未知語・別言語、口を動かさない内言、患者、自由な開始時刻、実時間応答、少数電極、長期運用、データ配布と独立再現。

### 後退・限定した軸

比較対象よりモデルが大きい。周波数の予測損失を加えると分類は改善する一方、波形予測誤差は必ずしも減らない。事前学習の改善も参加者全員には共通しない。

### 限界

- **技術：** 122チャネルと本人の学習記録に依存し、モデルは22.61Mパラメータ。周波数予測を加えた分類改善と波形誤差改善は一致しない。雑音除去の記述はあるが、分類情報が純粋な神経信号のみであることの独立した対照試験は示されない。
- **評価：** 12人それぞれで16収録中1つを検証、1つを試験に取り分ける。未知被験者評価や分割反復・学習乱数ごとの信頼区間は示されない。人数の括弧表記、試行反復数、意味分類の本文数値に不整合。2秒の前処理区間と1.5秒の無声課題の位置関係、ICAの分割独立性は明確でない。
- **実運用：** 着座して画面と音の合図に従う実験。多電極キャップ、外部増幅器、雑音除去を要し、携帯利用・歩行・自由会話・患者への有効性を評価していない。
- **このレビューの範囲：** 健常英語母語話者12人、24語・6意味群、画面と音の合図に従う無声調音、本人別の収録間評価。未知語・自然な文章・内言・患者・自由な発話開始は対象外。

### 根拠

- 健常な右利き英語母語話者12人（男女各6人）が参加。付録B.1は声を出さずに調音を試みるよう指示したと記し、口を動かさない内言とは区別される。（p.13 Appendix B and B.1）
- 本文4.1と図6は休憩5秒、単語提示1秒、準備0.2秒、無声発話1.5秒の合図付き試行。着座して動きを抑える実験である。（p.6 Section 4.1, Figure 6; p.13 Appendix B, Figure 11）
- 各人16収録・6000試行、各収録375試行、全体約120時間を報告。収録時間には休憩等が含まれ、無声発話区間だけの120時間とは確認できない。（p.6 Section 4.1; p.13 Table 7）
- 本文4.1の12人に付くS1-S10の括弧と12人分の表、各収録375試行と付録B.1の24語を各5回という記述は一致しない。推測で訂正しない。（p.6 Section 4.1; p.7 Tables 1–2; pp.13–14 Appendix B.1, Tables 7–8）
- 24語は動作・感情・場所・人物・物・数の6群に分かれる。分類の出力集合であり、自由な文章生成は評価していない。（pp.13–14 Appendix B.1, Table 8; p.6 Section 4.2.2）
- 128チャネル装置で1000Hz収録。保存データは122脳波、4眼球運動、6筋肉・環境雑音参照、1トリガーの133チャネル。脳波は1–75Hz帯域、50Hz除去、平均参照、ICA処理後250Hzへ変換する。（pp.13–14 Appendix B and B.2, Figure 12）
- 前処理は2秒区間・0.5秒重複と記す一方、無声課題は1.5秒。区間の位置関係、ICA等の分割独立性、除去後の筋電・眼電寄与の対照評価は十分明らかでない。（p.6 Section 4.1; p.14 Appendix B.2）
- FSTPは隠した波形・振幅・位相を復元するMSTPで初期学習し、その後未来の同3成分を予測するASTPへ進む。予測損失はHuber損失を用いる。（pp.4–5 Section 3.3, Figures 2 and 4, equations 4–6）
- 25点の脳波窓を6点ずつずらし、位置・本人の埋め込み表現、Conformerと層間ゲート、空間・時間分類器を使う。付録では4層・隠れ次元64を記載。（pp.3–6 Sections 3.1–3.4, Figures 3–5; p.13 Appendix A.6）
- 各人16収録中2つは事前学習・追加学習とも除外し、一方を検証・モデル選択、他方だけを試験に使う。ラベルなし約105時間を事前学習に使用し、分類は本人別に追加学習する。（p.6 Section 4.2.1; p.13 Appendix A.6）
- 表1の24語平均正解率は提案法39.6%、TCNet32.3%、事前学習なしLBLM35.3%、MSTPのみ36.9%。TCNetとの差7.3百分率ポイントと、同構造の事前学習なしとの差4.3百分率ポイントは異なる。（p.7 Table 1）
- 表2の6意味群平均正解率は提案法47.0%、TCNet41.6%、事前学習なしLBLM42.2%、MSTPのみ44.8%。TCNetとの差は5.4百分率ポイント。（p.7 Table 2）
- 本文5.1冒頭は意味分類42.8%とするが、同節の後段・表2・要旨は47.0%。表1の提案法は参加者別11.7〜73.8%で、S01などは事前学習なしを下回る。平均改善は全員改善ではない。（p.1 Abstract; p.6 Section 5.1; p.7 Tables 1–2）
- 表3でTransformer、Conformer、層間ゲートを加えた最終構造の単語/意味分類は25.5/39.8、31.3/42.7、39.6/47.0%。最終モデルは22.61Mパラメータ。（p.7 Table 3）
- 波形損失のみの単語/意味分類37.4/42.4%に対し、振幅・位相を加えると39.6/47.0%。一方ASTP波形MSE/MAEは0.23/0.28から0.27/0.32となり、分類改善が波形誤差低下を意味しない。（p.7 Section 5.2.2, Table 4）
- 表5の事前学習あり分類器は線形21.9/31.1%、畳み込み35.5/42.5%、提案する空間・時間分類器39.6/47.0%。比較した分類器によって事前学習の改善量が異なる。（p.8 Section 5.2.3, Table 5）
- 表6の文脈204点・未来46点予測では提案法MSE/MAE0.27/0.32、PatchTST0.84/0.62、TimesFM1.40/0.76。未来136点では提案法0.54/0.46となり誤差が増える。（p.8 Section 5.3, Table 6）
- 未来波形は予測開始後およそ30点（250Hzで120ミリ秒）までは実測とよく対応するが、その先ではずれが増すと本文は述べる。分類遅延や発話内容の先読み性能を測った値ではない。（p.8 Section 5.3, Figure 7; pp.15–16 Appendix C）
- 学習はH100上のPyTorch、LAMB、batch1024、初期学習率1e-3、重み減衰0.01、勾配上限1.0、振幅・位相の重み各0.1。付録は事前学習80epochと記す。（p.13 Appendix A.6）
- 図13は読字・休憩・無声発話の帯域別の差を示す解析であり、語を区別する神経情報だけの因果的証明ではない。本文の筋肉雑音に関する説明だけで残留混入を否定できない。（p.12 Appendix A.4; pp.14–15 Appendix B.3, Figure 13）
- 序論はデータセットを公開予定とする。本文中に利用可能な配布先は示されず、本レビューではコード・重み・原データの配布や再現を確認していない。（p.2 Section 1, contribution list; pp.1–16 full-text availability statements）
- 未来波形予測が電極断線の補完や実時間の信頼性に役立つと著者は提案するが、実験は波形誤差の比較であり、実機断線・対話遅延・日常運用の改善結果は示されない。（pp.8–9 Sections 5.3 and 6）
- 評価は本人別の24語・6群分類に限られ、未知の人・未知語・患者・口を動かさない内言・自由文・歩行の成績、学習乱数や分割反復に伴う信頼区間は示されない。（pp.6–8 Sections 4–5, Tables 1–6; pp.13–14 Appendix B）
