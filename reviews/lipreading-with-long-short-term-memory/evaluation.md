## Required fixes, ordered by impact

1. **Major. Verdict and M06, "what is new is recurrent memory over the word."** Evidence: the review's own [4] runs one diffusion network per word over lip-contour trajectories (quote v5); Rabi & Lu 1998 (J. Electronic Imaging 7(1), doi:10.1117/1.482627) classify words with a recurrent network over visual features; Tsunekawa et al. 2004 (ICIAR, doi:10.1007/978-3-540-30126-4_50) use a recurrent prediction model for lipreading. Fix: replace with "what is new is a gated recurrent model trained jointly with a pixel-input front end; recurrent word models over pre-extracted lip features existed from 1998-1999 [4]". Optionally add Rabi & Lu 1998 as a prior (do not call it a missed citation unless read).

2. **Major. Verdict and M06, repetition behind `ahead`: "the gain repeats on two disjoint speaker groups".** Evidence: Sec. 3, speakers 1-9 "used to determine the parameter settings". Fix: "the gain holds across the 10 evaluation speakers (79.6% ± 4.3 vs 71.3% ± 4.3, Table 1), on one corpus with no seeds; speakers 1-9 were the tuning group". Keep `ahead` only with this wording, and add in the same sentence that the repeated effect is over linear SVMs, so the evidence shows the design is new, not that it beats the HMM pipeline of the time.

3. **Major. M04 state of the art.** Evidence: LRW clips are pre-cut around the target word in both SyncVSR conditions; the 95.0 vs 93.2 contrast is about boundary indicators within a pre-cut clip. Fix: drop the 1.8-point gap as the M04 gap, or say plainly that both LRW numbers use pre-cut word clips; make the sentence-level GRID/LRS decoding the M04 state of the art, and state the gap as "word given vs sentence decoded".

4. **Major. Concurrent work not labelled (M06).** Evidence: Petridis & Pantic, "Deep Complementary Bottleneck Features for Visual Speech Recognition", ICASSP 2016 (wiki doi-10.1109-icassp.2016.7472088, abstract and Sec. 4.2): pixel-derived DBN bottleneck features + DCT fed to an LSTM, stage-wise training. Fix: one sentence: "[concurrent] Petridis and Pantic (ICASSP 2016) also feed pixel-derived features to an LSTM, but train the feature network and the LSTM separately." Add the concurrent count to the Appendix (audit: 1, plus the date-unresolved 23, of which 7 name a recurrent network).

5. **Medium. M12 state of the art.** Evidence: LinProVSR names no GRID split and compares against unseen-speaker methods. Fix: cite a GRID result on an explicitly named protocol (overlapped/seen vs unseen speakers) from a read source, or say that LinProVSR is the best GRID number but its protocol is not stated and therefore gives no protocol comparison; the current "split type not named" is honest but leaves M12 without a usable state of the art.

6. **Medium. M04 and M12 usual-approach vs verdict.** Evidence: table "Continuous decoding named (65)" and "Speaker-independent named (52)" against `standard`. Fix: write the usual approach as "both named: continuous 65, isolated 41 (pattern match, mentions)" and "both named: speaker-independent 52, speaker-dependent 37", and state that `standard` rests on both designs being common, as the rule's second clause allows.

7. **Medium. Target abstract overreach missed.** Evidence: abstract "79.6% on held-out evaluation speakers" vs Sec. 3 "All experiments are speaker-dependent". Fix: add a bullet under "Where the claims outrun the evidence": the abstract's "held-out evaluation speakers" reads as speaker-independent; the speakers were held out from tuning only.

8. **Minor. Counts presented as designs.** Evidence: audit inclusion rule counts related-work mentions. Fix: in the Verdict add "(pattern match, mentions)" after "113 name an HMM and 2 a recurrent network"; in "The only baselines..." write "113 of 159 prior studies name one (pattern match)".

9. **Minor. Misdated prior study.** Evidence: `arxiv-1710.01073` (Bear, ISVC Dec 2015) is in the prior HMM and hand-crafted lists. Fix: move it to [concurrent]; prior becomes 158, HMM 112, hand-crafted 97 (inference); update all three topics' prior counts if it is in them.

10. **Minor. Deep-feature generalisation.** Evidence: of the 4 deep-feature hits, only [6] and [7] were read; Mroueh 2015 uses scattering + LDA features. Fix: "The two read deep-feature priors train features apart from the classifier ...".

11. **Minor. Process note in the body.** Location: M06, "A whole-wiki full-text check (34 matching studies, Appendix) adds none." Fix: delete from the body; the Appendix already states it.

12. **Minor. Duchnowski lineage.** Evidence: Duchnowski l. 127-129, "In our first work [2], pictures of the lip region were manually extracted", referring to the group's 1993 pixel-input system. Fix: optional; "restates a 1994 capability" is still correct, but "the closest prior" can note the 1993 origin. Also mention that Duchnowski is one speaker, audio-visual, continuously spelled letters, so it is not a like-for-like visual-only word task.

13. **Minor. Standardization bullet weight.** Fix: add "global z-scoring leaks only the pooled mean and SD (inference)" so that the point is not read as a major leakage.

No summary or method walkthrough beyond what each section needs to state the departure; the 13-components table and Appendix are in the required form. Fairness is kept: the authors' HMM hypothesis, CNN remark and future speaker-independent work are reported before being criticised; no [later] work is treated as prior.
